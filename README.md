Dicee 🎲

An interactive dice-rolling application built with Flutter and Dart.

This project explores stateful widgets, random number generation, and responding to user interactions to update a mobile application’s interface.

📱 Overview

Dicee is a simple dice application that allows users to roll dice by interacting with the screen.

Each interaction generates randomized dice values and updates the displayed dice images.

✨ Features

* Interactive dice-rolling functionality
* Randomized dice outcomes
* Dynamic image updates
* Responsive user interactions
* Simple, intuitive interface

🛠️ Tech Stack

* Framework: Flutter
* Language: Dart
* Concepts: Stateful widgets, event handling, and random number generation

📚 Key Learnings

* Managing application state with StatefulWidget
* Using setState() to update the UI
* Generating random values with Dart
* Handling button presses and tap gestures
* Displaying images based on application state

🚀 Getting Started

Prerequisites

* Flutter SDK
* Dart SDK
* A configured emulator or physical device

Installation

1. Clone the repository:

git clone https://github.com/vsroshan/flutter-dicee.git

2. Navigate into the project:

cd flutter-dicee

3. Install dependencies:

flutter pub get

4. Launch the application:

flutter run
